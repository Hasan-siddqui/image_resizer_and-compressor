# 📷 Image Resizer & Compressor  

**[Live Demo](https://hasan-siddqui.github.io/image_resizer_and-compressor/)**  

A **free online tool** to resize and compress images effortlessly. Adjust width, height, aspect ratio, quality, and file format while maintaining high visual quality.  

---

## 🚀 Features  

✅ **Drag & Drop Upload** – Upload images easily  
✅ **Resize Images** – Set custom width & height  
✅ **Maintain Aspect Ratio** – Auto-lock to prevent distortion  
✅ **Compress Images** – Reduce file size without losing quality  
✅ **Multiple Formats** – Supports **JPEG, PNG, WebP**  
✅ **Preview Before Download** – View changes instantly  
✅ **Download Optimized Image** – Save compressed images quickly  

---

## 🔧 How It Works  

1️⃣ **Upload** an image by dragging & dropping or clicking the upload box  
2️⃣ **Adjust** width, height, aspect ratio, and quality settings  
3️⃣ **Select** the desired file format (**JPEG, PNG, WebP**)  
4️⃣ Click **"Resize & Compress"** to process the image  
5️⃣ **Download** the optimized image  

---

## 🛠️ Technologies Used  

- **HTML5** – For structure  
- **CSS3** – Modern UI design  
- **JavaScript (Vanilla JS)** – Image processing  
- **Canvas API** – Handles resizing & compression
